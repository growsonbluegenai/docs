This path is for government offices and contracted teams with existing contract vehicles who need to align stakeholders and secure leadership approval before development work begins.

<Note>
  There's no competitive proposal to write here — the resources are already in place. Phase 1 in this context is about alignment: getting stakeholders to agree on what the modernized system should look like before development begins.
</Note>

## How this phase works under contract

The outputs are prototypes for leadership review, concept of operations documents, and solution narratives for internal approval.

<Warning>
  The HTML prototype generated in the Prototype tab is functional rendered code — not yet deployed to a production environment, but one click away from becoming one. Switching to the Build tab converts it into a fully deployed application. Your stakeholder alignment prototype is essentially production-ready.
</Warning>

This phase is optional. If alignment already exists, you can skip directly to Phase 2.

## Generate a stakeholder alignment prototype

<Steps>
  <Step title="Create a new project">
    Start a new BlueGenAI project.
  </Step>
  <Step title="Upload existing documentation">
    Include requirements docs, process flows, and screenshots of the current system alongside any documentation of the desired future state.
  </Step>
  <Step title="Describe the modernized system">
    Write a prompt describing what the modernized system should do.

    For example: _"Generate a prototype of a modernized permit tracking system for a state agency. The current system is a legacy desktop application. The modernized version should be web-based, accessible, and allow residents to submit and track permit requests online."_
  </Step>
  <Step title="Review and iterate">
    Click Send, review the generated prototype, and continue iterating until it reflects the agreed-upon vision.
  </Step>
</Steps>

## Generate a concept of operations document

Prompt the agent directly, referencing any uploaded documentation for context:

> "Generate a concept of operations document for the modernization of our permit tracking system. Include current state summary, future state vision, key stakeholders, and high-level implementation approach."

Save and share the generated document for leadership review.

## Use the prototype for leadership sign-off

<Steps>
  <Step title="Generate a shareable link">
    Available from Project Settings.
  </Step>
  <Step title="Share with leadership and stakeholders">
    Send the link for asynchronous review, or use the prototype in a live presentation.
  </Step>
  <Step title="Collect feedback and iterate">
    Refine the prototype before proceeding to Phase 2.
  </Step>
  <Step title="Disable the link after review">
    Return to Project Settings once the review period ends.
  </Step>
</Steps>

## When to skip Phase 1

Proceed directly to Phase 2 if:

- Stakeholder alignment already exists and leadership has approved the modernization direction.
- The existing contract already defines the scope clearly enough to begin requirements work.
