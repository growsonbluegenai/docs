Quick reference for acronyms and abbreviations used across this portal. Terms are listed alphabetically by acronym.

| Acronym | Name | Description |
| --- | --- | --- |
| AI | Artificial Intelligence | The technology underlying BlueGenAI's agents — used throughout the platform to generate prototypes, requirements, code, and documentation from natural-language prompts. |
| API | Application Programming Interface | A defined way for software systems to communicate. BlueGenAI-generated backends expose REST APIs, and BlueGenAI itself can integrate with external platform APIs. |
| ASP | Active Server Pages | A legacy Microsoft web development technology ("Classic ASP") sometimes found in older systems analyzed by CAB. |
| AS/400 | Application System/400 | A legacy IBM midrange computing platform sometimes encountered in government legacy systems analyzed by CAB. |
| ATO | Authority to Operate | Formal government approval for a system to run in a production environment. Requires documented evidence the system meets security requirements. |
| ATT | Authority to Test | Formal government approval for a system to enter a testing environment, ahead of full ATO. |
| BD | Business Development | Pre-award work — proposal writing, capture strategy, and client engagement — typically performed by contractors and integrators pursuing government contracts. |
| CAB | Common Application Blueprint | BlueGenAI's capability for analyzing existing documents, source code, and legacy systems to produce a comprehensive architectural blueprint. |
| COBOL | Common Business-Oriented Language | An older programming language frequently found in mainframe legacy systems that CAB can analyze. |
| CUI | Controlled Unclassified Information | Government-created or government-owned information requiring safeguarding or dissemination controls under law, regulation, or government-wide policy. |
| DDL | Data Definition Language | Database scripts that define schema structure (tables, relationships). Useful CAB input when modernizing a legacy system's data model. |
| DUNS | Data Universal Numbering System | A legacy entity-identifier system used in federal contracting, replaced by UEI in 2022. |
| FAQ | Frequently Asked Questions | A common support-content format, referenced in the Help & Support tab. |
| FedRAMP | Federal Risk and Authorization Management Program | A government-wide standardized approach to security assessment, authorization, and continuous monitoring for cloud products and services. |
| ICD | Interface Control Document | A procurement-recognized document describing how two systems interface. BlueGenAI can generate ICDs as part of its compliance-friendly outputs. |
| ITAR | International Traffic in Arms Regulations | U.S. regulations controlling the export and import of defense-related articles, services, and technical data. |
| J2EE | Java 2 Platform, Enterprise Edition | An older Java enterprise framework sometimes found in legacy systems CAB analyzes. |
| JAD | Joint Application Design | A structured workshop format used to gather and refine requirements directly with stakeholders. |
| JCL | Job Control Language | Scripting used to run batch jobs on mainframe systems — relevant input when using CAB on legacy mainframe applications. |
| LLM | Large Language Model | The class of AI model that powers BlueGenAI's prompt-driven generation. |
| PDF | Portable Document Format | A common document format supported for uploads (e.g., solicitations, requirements) and for exported outputs. |
| PL/SQL | Procedural Language/Structured Query Language | Oracle's procedural extension to SQL, often found in legacy database logic analyzed by CAB. |
| RFI | Request for Information | A pre-solicitation document used by government agencies to gather information from potential vendors. |
| RFP | Request for Proposal | A solicitation document inviting vendors to submit a proposal for a described scope of work. |
| RFQ | Request for Quote | A solicitation document requesting pricing for a defined scope, typically used for simpler procurements than an RFP. |
| RPG | Report Program Generator | A legacy programming language associated with IBM AS/400 systems. |
| RTM | Requirements Traceability Matrix | A document mapping each requirement to its corresponding user story, design element, and test case — a common procurement-friendly output BlueGenAI generates. |
| SAM | System for Award Management | The federal government's official registry for entities doing business with the government; issues UEI numbers. |
| SDD | System Design Document | A procurement-recognized document describing a system's technical design — a common BlueGenAI output. |
| SME | Subject Matter Expert | A person with specialized knowledge of a domain, process, or system — often needed to validate AI-generated content for undocumented workflows. |
| SOC | System and Organization Controls | Audit reports certifying a service organization's controls are designed and operating effectively. SOC 2 Type II is most relevant to cloud-based platforms. |
| SOO | Statement of Objectives | A solicitation document describing high-level goals without prescribing a specific approach, giving vendors flexibility in their proposed solution. |
| SOR | Statement of Requirements | A document listing specific requirements a solution must meet, often used alongside or instead of a SOW. |
| SOW | Statement of Work | A document defining the scope, deliverables, and terms of a specific project or contract. |
| SQL | Structured Query Language | The standard language for querying and managing relational databases. |
| SSN | Social Security Number | A sensitive personal identifier that BlueGenAI-generated applications should avoid collecting unless explicitly required and appropriately secured. |
| T-SQL | Transact-SQL | Microsoft's procedural extension to SQL, often found in legacy database logic analyzed by CAB. |
| TAP | Tyler Application Platform | A low-code, configurable platform used for case management and business process workflows in the public sector. One of several low-code platforms BlueGenAI can generate configurations for. |
| UEI | Unique Entity Identifier | A 12-character alphanumeric identifier assigned by SAM.gov to entities doing business with the federal government. Replaced the DUNS number in 2022. |
| UI | User Interface | The visual and interactive elements of an application that users see and work with. |
| URL | Uniform Resource Locator | A web address — used throughout the platform to reference live application links, shareable prototypes, and documentation pages. |
| VB6 | Visual Basic 6 | A legacy Microsoft programming language and IDE, sometimes found in older systems analyzed by CAB. |
| WCAG | Web Content Accessibility Guidelines | The standard used to define accessibility requirements (e.g., WCAG 2.1 AA) for applications built for the public sector. |
| WCF | Windows Communication Foundation | A legacy Microsoft framework for building service-oriented applications, sometimes found in older .NET systems analyzed by CAB. |
| ZIP | — | A compressed archive file format. The preferred way to upload full codebases or multi-file document sets to CAB. |

<Note>
  Some terms above (WCAG, SSN) are drawn from source material for phases not yet published. They're included here so the Glossary stays ahead of content development rather than needing repeated updates.
</Note>
