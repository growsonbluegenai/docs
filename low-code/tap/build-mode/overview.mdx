Build Mode is the point at which configuration reaches your TAP site. It becomes available once a site is linked to the project, and changes are applied to that site directly rather than staged for later.

For the full inventory of what can be configured, see [Component Reference](/low-code/tap/build-mode/component-reference). To agree a shape before anything reaches the site, start in [Prototype Mode](/low-code/tap/prototype-mode/overview).
