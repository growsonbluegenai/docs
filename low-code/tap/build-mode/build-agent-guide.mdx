---
title: "Build Agent Guide"
description: "Why TAP Build Mode uses several agents rather than one, and what that means for how you phrase a request."
---

TAP Build Mode is not served by a single agent. The work is divided among specialists, each owning one part of a configuration: forms, workflows, administration, reports, and queues.

That division is worth knowing when you write a request. Asking for a form change and a workflow change in one sentence engages two specialists, and naming both explicitly gets a cleaner result than leaving the split implicit.
