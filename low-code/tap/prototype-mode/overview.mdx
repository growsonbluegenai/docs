title: "Overview"
description: "What TAP Prototype Mode produces, and what it deliberately leaves untouched."
icon: "rocket"
---

Prototype Mode is the only way to see a TAP design before any configuration reaches your site. Its agent produces a data model and an HTML mockup, and it does not connect to your TAP environment, so nothing it does can affect a live site.

That is what makes it the right place to settle a shape with stakeholders. See [Workflow](/low-code/tap/prototype-mode/workflow) for how a run proceeds, and [Output Handoff](/low-code/tap/prototype-mode/output-handoff) for carrying the result into Build.
