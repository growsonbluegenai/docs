---
title: "Output Handoff"
description: "What carries forward from a TAP prototype, and why that saves repeating the discovery step."
---

A prototype is only worth building if its output survives the move into Build. The files a run produces are saved to the project, which is what lets a Build request start from an agreed data model rather than from the original source material again.

See [TAP Build Mode](/low-code/tap/build-mode/overview) for what happens to that output once configuration starts reaching your site.
