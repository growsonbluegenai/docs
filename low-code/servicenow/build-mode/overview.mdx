---

Build Mode is where configuration reaches your ServiceNow instance. It becomes available once an instance is connected, and changes are applied through the instance APIs rather than by driving its interface.

There is no prototype step on ServiceNow, so a build changes the connected instance. That is why configuration is normally applied to a development instance. The full inventory of what can be configured is in [Component Reference](/low-code/servicenow/build-mode/component-reference).
