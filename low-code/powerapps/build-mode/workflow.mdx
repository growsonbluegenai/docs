---
title: "Workflow"
description: "What a PowerApps Build request carries, and what comes back."
---

A PowerApps request returns two kinds of result, and telling them apart matters. Changes to schema, forms, views, and business rules come back as applied. Security roles, flows, and form scripts come back as specifications for you to apply.

Read the response for which of the two you received before assuming a change is live in the environment.
