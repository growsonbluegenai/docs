---
title: "Salesforce"
description: "Salesforce projects: what is supported today, and what is not yet documented."
---

Salesforce is available as a low-code target when you create a project, and a build requires credentials for the target org in the same way the other low-code platforms require a connected site or environment.

Its configuration surface is not yet documented here. For the platforms covered in detail, see [TAP](/low-code/tap/overview), [ServiceNow](/low-code/servicenow/overview), and [PowerApps](/low-code/powerapps/overview).
