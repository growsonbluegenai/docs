The platform has two levels: a dashboard listing your projects, and a workspace you enter by opening one.

## What you'll learn

Where things are, what the four modes do, and how to reach the panels that sit alongside them.

## The dashboard

<Frame caption="The dashboard. Every project you own or can see, with a platform badge on each card.">
  ![The Projects dashboard showing a search field, an Application Type filter, tabs for My Projects, Shared with Me and Invitations, and a grid of project cards each carrying a platform badge.](/images/getting-started/navigation-ui-guide-dashboard.png)
</Frame>

Three tabs, each with a count: **My Projects**, **Shared with Me**, and **Invitations**. Search by name, sort, or filter by platform.

Each card shows the project name, an optional client label, when it was last updated, and a badge naming its platform — `Web`, `TAP`, `SN`, or `SF`. Hovering a card reveals a menu with **Open**, **Edit**, **Clone**, **Manage Collaborations**, and **Delete**.

## Inside a project

Opening a project takes you to its workspace. **There are two, and which one you get depends on the project's platform** — web projects and low-code projects have different workspaces because they build different things. You do not choose; opening the project takes you to the right one.

  ![A project workspace showing mode tabs for CAB, Tickets, Prototype and Build, with a two-pane layout below and a row of panel icons at the top right.](/images/getting-started/navigation-ui-guide-workspace.png)

## The four modes

Every project workspace has the same four modes, selected from the tabs at the top left.

| Mode | What you do there |
| --- | --- |
| **CAB** | Generate and correct the specification your project is built from |
| **Tickets** | Break that specification into units of work and order them |
| **Prototype** | Build a front end to look at and click through |
| **Build** | Build the real application, with data behind it |

**These are modes, not pages.** Switching mode changes what fills the workspace, not where you are — you stay in the same project throughout, and your place in each mode is remembered when you come back.

## The panel rail

The icons at the top right open panels beside your work. **Ten in Prototype Mode, eleven in Build**, which adds Testing Context.

| Panel | What it holds |
| --- | --- |
| Files | Everything uploaded to or generated by the project |
| Design System | Colours, type, and spacing for generated prototypes |
| URLs | Your running application's addresses |
| Preview | The running application, embedded |
| Codebase | The generated source, and the version-control controls |
| Database | The application's data, browsable and queryable |
| Credentials | Keys the agent has asked you for |
| MCP Servers | External tools connected to the build agent |
| Testing Context | What the testing agent should know — **Build only** |
| Stop App | Stops the running application |
| Manage Collaborators | Invitations and sharing |

The icons carry no visible labels. Hover one for about a second to see its name.

## Getting help

The top bar carries a dark-mode toggle, a notifications bell, a help link, and your account menu. A breadcrumb to the left shows which project you are in, with a home icon back to the dashboard.
